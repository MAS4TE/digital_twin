# MAS4TE_ULIEGE

## Documentation

Documentation available locally through the following commands:

`cd docs`
`make hmtl`
`open docs/_build/html/index.html`

## Set up

1. Create or load a virtual environment for Python with Python 3.14.3.
2. Add the required packages in the correct version, with:

`pip install -r requirements.txt`

3. Add the required data files in a folder named data (**you have to create it**). This folder is ignored by GIT to avoid poluting the repo with huge amounts of data. Required files are presented in the documentation.
